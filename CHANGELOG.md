# Changelog

All notable changes to `paybridge-django` will be documented in this file.

The format is based on Keep a Changelog and the project follows Semantic Versioning.

## [0.1.0] - 2026-05-07

- Initial reusable Django app release
- Paystack, Flutterwave, and Stripe gateway services
- Transaction and subscription models with Django admin support
- Webhook views, signals, management commands, and optional Celery tasks
- Example Django project, pytest suite, and PyPI release workflows
